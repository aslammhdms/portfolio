# Scene videos

Full-bleed scroll-scrubbed backdrops, one per section. The `*.v1.mp4` / `*.v1.webm`
clips currently here are **procedural placeholders** generated by
`scripts/gen-placeholders.sh` so the scroll engine works before the real footage exists.

## Replacing with real Higgsfield clips

1. Generate 5 clips in Higgsfield following the shot list (dark · slow · abstract ·
   16:9 · 6–10s · loopable · indigo `#7C6CFF` / teal `#39E0C8` over near-black `#0A0C10`):
   `hero · about · skills · projects · contact`.
2. Save the raw exports to `public/videos/src/<scene>_raw.mp4` (this folder is gitignored).
3. From the repo root: `bash scripts/encode-videos.sh` — re-encodes them all-keyframe
   (smooth scrubbing) + faststart, and writes the `.mp4`, `.webm` and `.poster.webp` here.
4. If you re-export later, bump the version in `src/scenes/clips.ts` (`v1` → `v2`) so
   caches don't serve the old clip (Vite doesn't content-hash files in `public/`).

Filenames are referenced by `src/scenes/clips.ts`; keep them stable.
